Hilbert Soh — Drone-Guided Autonomous Navigation & Obstacle Avoidance

Hilbert Soh

Drone-Guided Autonomous Navigation and Obstacle Avoidance for UGV

Matric: A0308263H

Hilbert Soh is responsible for leading the autonomous navigation pipeline and communications infrastructure for the UGV platform. This includes establishing telemetry and command links with the UAV, deploying ROS 2 navigation and SLAM pipelines, executing high-precision path routing with real-time dynamic obstacle avoidance in unstructured airfield environments, and engineering automated fail-safe safety protocols.

📡 Read Hilbert's Deep-Dive Communication Spec (Microhard P900 V2) →
🎯 Engineering Scope Objectives
  • Establish Link: Receive dynamic aerial target waypoints over secure telemetry radio from the UAV platform.
  • Autonomous Routing: Execute high-precision path planning and trajectory following to reach goal locations.
  • Dynamic Avoidance: Real-time local obstacle detection and re-routing in unstructured outdoor airbase environments.
🛠️ Technical Execution & Responsibilities
  • Messaging Architecture: Design and deploy a custom ROS 2 message parser/validator to process incoming UAV coordinate streams.
  • SLAM & Localization: Configure and fine-tune SLAM Toolbox for 2D/3D map generation in sparse airfield landscapes.
  • Path Planning: Implement Nav2 controller and planner plugins for waypoint execution with dynamic obstacle clearance.
  • Fail-safe Protocols: Implement heartbeat monitors and automated emergency stop logic triggered upon signal loss.

📦 Expected Deliverables
Phase 1 Deliverables
  • Autonomous UGV Navigation: Tested and validated in Gazebo and RViz2 simulation (ROS 2 Jazzy on Ubuntu 24.04).
  • Simulated Communications: Reliable link and coordinate transmission with simulated UAV (running on Raspberry Pi 5 or Charan's Laptop) via local router CycloneDDS.
Phase 2 Deliverables
  • Physical Navigation Implementation: Full Nav2 deployment and motion control on actual physical UGV via STM32 F446RE.
  • Long-Range RF Communications: Robust telemetry and coordinate relay with UAV using dedicated RF module.
Key Milestones & Demonstration Targets
  • Drone-to-UGV Bridge: Fully integrated waypoint parsing communication module.
  • Navigation Stack: Tested ROS 2 autonomous mapping & navigation pipeline.
  • Field Demonstration: Live dynamic obstacle avoidance trial using cued coordinates.
  • Telemetry Report: Performance analytics on navigation drift, latency, and avoidance reaction times.
