## Conclusion {#conclusion}

In Semester 1, the team set out to build a critical function prototype of FOD Hunter, and each system has now shown its core function. Navigation has been run in simulation, communication has been tested between onboard computers, the vision model has been benchmarked on small hardware, the suspension keeps all four wheels on the ground, the vacuum picks up light FOD, and the power system has been sized for the prototype.

Semester 2 moves the project from separate prototypes to one working system. The suspension will be redesigned for CNC machining, and two FOD tools, one for small objects and one for bulkier items, will be developed and fabricated over the vacation. The navigation and vision software will then be integrated on the physical FOD Hunter and tuned, while the electrical system is finalised with safety features and a charging platform for the drone. In weeks 5 and 6, the team will gather user feedback and validate the system, with a site visit if possible, ahead of the final report and presentation.
