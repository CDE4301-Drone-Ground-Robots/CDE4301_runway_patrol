Autonomous Navigation & SLAM. Nav2 Architecture & Pure Pursuit.

ROS 2 Jazzy Nav2 stack implementation, cost-aware Smac 2D global path planning, Regulated Pure Pursuit local controller, SLAM Toolbox mapping, and EKF sensor fusion.

SECTION 1.0

Nav2 Autonomy Stack Architecture

View Navigation Section →

The autonomous navigation framework coordinates global sweep paths over 60-meter wide airfield tarmac corridors while executing real-time obstacle avoidance at 20 Hz.

🧭 Global Path Planning (Smac 2D)

A* search with Dubins path smoothing. Generates straight runway corridors and turnaround hairpin loops in <8 ms, maintaining safe offset from runway taxiway edges.

⚡ Regulated Pure Pursuit Controller

Calculates angular velocity $\omega$ at 20 Hz with dynamic lookahead distance ($0.6\text{--}1.8\text{ m}$). Enforces curvature-regulated deceleration during turnaround loops to prevent tire slippage.

SECTION 2.0

Sensor Fusion & Pose Estimation

robot_localization EKF
# Launch Nav2 autonomous navigation with lifelong SLAM Toolbox
ros2 launch runway_nav bringup_launch.py use_sim_time:=false autostart:=true
  • Primary Odometry: Dual hub-motor optical encoders (4,096 PPR) publishing /odom/wheel at 50 Hz.
  • Inertial Reference: 6-DOF IMU publishing orientation & angular velocity at 100 Hz.
  • Global Correction: RTK GNSS dual-antenna compass publishing centimeter-accurate global fix at 10 Hz.
  • Fusion Method: Dual-tier Extended Kalman Filter (EKF) with continuous drift rejection.
